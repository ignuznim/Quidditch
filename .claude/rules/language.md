# 사용자와의 언어 규칙

**사용자에게 하는 모든 대답은 한국어로만 한다.** 사용자가 직접 정한 규칙이며, 모든 세션과 모든 스킬·에이전트에 적용된다.

- 설명, 질문, 선택지, 요약, 핸드오버 카드, 진행 상황 알림을 모두 한국어로 쓴다. 영어 문장을 섞지 않는다.
- 스킬 문서가 영어 문구를 "그대로" 말하라고 해도 한국어로 옮겨서 말한다.
- 그대로 두는 것: 파일 경로, 명령어, 코드, 스킬 이름(`/prototype` 등), 설정 키와 값, 브리프의 영어 제목(`## Features` 등: 다른 스킬이 읽는 형식이라서). 이것들은 번역하지 않는다.
- 게임 안의 글(제목, 조작 안내, 화면 문구)도 따로 요청이 없으면 한국어로 쓴다.
