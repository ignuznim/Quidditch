After play: 게임보이 기기 재현을 좀더 디테일하게 해줘. 지금은 폰트나 버튼의 모양이 정확하지 않은 것 같아. 플레이어 인원수가 실제 퀴디치처럼 많으면 좋겠고, 공 종류도 실제 개수와 같길 원해. 방망이로 공을 쳐서 날리는 행위를 하는 플레이어도 두고, 나는 파수꾼 역할을 부여하면 좋겠어.
After play: 미안 잘못 말했다. 수색꾼으로 플레이하게 해줘. 그리고 스타트 셀렉트 버튼의 글자가 버튼 모양과 겹치는 문제 해결해줘. 십자 방향키 버튼의 가로 세로 방향이 가운데서 겹쳐보이는 문제 해결해줘. 게임보이 디자인은 첨부한 사진을 참고해서 최대한 똑같이 만들어줘. 게임 리스트를 만들고 몇 가지 게임 리스트 중 퀴디치를 선택할 수 있게 해줘. 추후 게임을 더 디자인해서 추가하자.
After play: 아이폰 기준 풀스크린으로 만들어줘. 웹앱으로 사용할 거야. 그리고 아이콘도 만들어줘. 게임보이라고 이름 수정하고.
After play: 첨부한 사진 보고 게임보이 기기 속 버튼, 스피커부분 등 음영 및 위치, 버튼의 형태 전면 수정해. 이걸 제대로 해결할 때까지 답변 주지마.
After play: 게임보이에 적힌 텍스트도 그대로 옮겨. (저작권 무시) 버튼과 파인 홈 사이의 간격이 일정하게 수정헤. 아이콘도 수정해. 앱 이름도 게임보이로. 이이콘은 텍그트로 게임보이인 버전, 기기를 작게 표현한 버전, 너의 아이디어로 제안하는 버전 3가지로 보여줘. 보여주면 선택하고 수정할게

**Pitch:** 회색 휴대용 게임기 모양의 화면에서 게임 목록 중 퀴디치를 골라, 7 대 7로 날아다니는 경기 속 그리핀도르의 수색꾼이 되어 블러저를 피하며 골든 스니치를 슬리데린 수색꾼보다 먼저 잡는 캐주얼 공중 구기 *(inferred (strong))*

**Genre:** 아케이드 스포츠 + 비행 *(inferred (strong))*

**Controls:** 키보드: 방향키/WASD 날기, Z 또는 X = 돌진(가까울 때 순간 가속), Enter 일시정지, M 소리. 게임기 틀: 십자키, A·B 돌진, START 일시정지, SELECT 소리. 목록: 위·아래로 고르고 A·START로 시작, B는 목록으로

**Question:** 수색꾼이 되어 스니치를 쫓는 퀴디치 한 판이 2분 안팎으로 재미있는가? *(guessed)*

**Hooks:** 실제 퀴디치 그대로: 팀마다 파수꾼 1·추격꾼 3·몰이꾼 2·수색꾼 1, 공은 퀘이플 1·블러저 2·골든 스니치 1. 나는 수색꾼: 경기가 펼쳐지는 동안 몰이꾼이 쳐 보내는 블러저를 피하고, 20초에 나타나는 스니치를 쫓아 돌진으로 잡으면 +150점에 경기 끝. 슬리데린 수색꾼은 6초 늦게 쫓기 시작한다. *(you said, inferred (strong))*

**Intent:** payoff builds *(provisional)*: 골든 스니치는 20초에 나타나고, 내가 6초 먼저 쫓을 수 있다.

## Look and references
- Look: 알록달록한 도트 스타일. 파란 하늘 띠와 체크무늬 섞기, 흰 구름, 초록 언덕, 깃발 단 돌탑, 알록달록한 관중석. 우리 팀 '그리핀도르'는 주황 두건과 망토, 상대 '슬리데린'는 청록 옷에 뾰족한 검은 모자와 금빛 부리, 퀘이플는 빨간 공, 블러저는 주황 불꽃 테두리의 검은 쇠공, 골든 스니치는 흰 날개의 금빛 공. 외곽선은 1픽셀 진남색, 음영 없음. 글자는 도트가 아니라 화면 해상도로 또렷하게. 대표 디테일: 고리 위 등불과 하늘의 등불 줄이 골 때 깜빡이고 관중이 뛰어오른다. 모든 선수와 공은 도트로 그리고, 이모지나 그냥 동그라미는 쓰지 않는다.
- References: 없음

## First minute
게임기를 켜면 POCKET 글자가 내려오고 게임 목록이 뜬다. 퀴디치를 고르면 경기장 위에 14명이 날아오르고, 나는 높이 뜬 그리핀도르 수색꾼. 방향키로 날아 보는 사이 추격꾼들이 퀘이플을 주고받고 몰이꾼이 블러저를 쳐 보낸다. 20초에 종소리와 함께 골든 스니치가 나타나면 쫓아가고, 가까워지면 돌진해서 잡는다. *(guessed)*

## Challenge
스니치는 가까이 오는 수색꾼을 보면 옆으로 확 꺾어 달아난다. 슬리데린 수색꾼은 6초 뒤부터 쫓고, 1분쯤부터 더 빨라진다. 블러저는 아무나 노리고, 맞으면 잠깐 휘청여서 놓치기 쉽다. 지면 결과 화면에서 바로 다시 하거나 목록으로 돌아간다. *(provisional)*

## Core loop
- 높이 날며 블러저를 피하고 스니치가 나타나기를 기다린다
- 스니치가 나타나면 쫓는다; 달아나는 방향을 읽고 가까울 때 돌진
- 슬리데린 수색꾼보다 먼저 잡으면 +150, 경기 끝; 그동안 추격꾼들의 골(10점)이 점수를 바꾼다
- 결과 → 다시 하기 또는 게임 목록
- Leads: 스포츠가 득점·경기장·시간을, 비행이 조작감과 화면 스크롤을 이끈다 *(inferred (strong))*

## Goal & fail state
- 수색꾼이 골든 스니치를 잡으면(+150) 경기 끝; 3분이 지나면 점수 높은 팀이 승리 *(provisional)*
- 끝났을 때 점수가 낮으면 패배, 결과 화면에서 선방·실점·패스 수를 보고 바로 다시 하기 *(provisional)*

## Features
- [x] 옆에서 보는 2D 비행: 8방향 이동과 약간의 관성, 돌진
- [x] 실제 퀴디치 인원: 팀마다 파수꾼 1·추격꾼 3·몰이꾼 2·수색꾼 1 (14명), 나 말고는 모두 AI
- [x] 나는 그리핀도르 수색꾼: 스니치를 쫓아 돌진으로 잡기, 6초 먼저 출발
- [x] 실제 공 개수: 퀘이플 1, 블러저 2, 골든 스니치 1
- [x] 몰이꾼: 방망이로 블러저를 쳐서 상대에게 날림, 맞으면 휘청하며 공을 놓침
- [x] 추격꾼과 파수꾼 AI: 패스, 압박, 빼앗기, 슛, 선방
- [x] 점수와 시계, 지는 팀 보너스, 결과 화면과 다시 하기·목록으로
- [ ] 알록달록한 도트 그림과 또렷한 글자, 골 등불과 관중 연출, 삑삑 효과음
- [x] 휴대폰 터치 조작: 십자키와 A·B·START·SELECT
- [x] 게임기 틀: 실제 사진에서 잰 위치(본체 폭 100 기준)대로 위쪽 턱과 OFF·ON, 오른쪽에 치우친 문구와 양쪽 줄무늬의 화면 테두리, 전원 불빛, 둥근 홈 안의 한 덩어리 십자키(미끄럼 방지 홈·가운데 오목), 주변 작은 화살표, 기울어진 홈 안의 자주색 A·B, 각자 홈에 든 연보라 SELECT·START와 같은 각도의 글자, 오른쪽으로 기운 스피커 구멍 6개, 아래 홈, 왼쪽 위에서 오는 빛의 음영 (회사 로고와 상표 글씨 대신 우리 이름)
- [x] 켜면 나오는 부팅 화면과 게임 목록 (퀴디치 + 준비 중 칸 셋)
- [x] 아이폰 홈 화면 웹앱: 전체 화면(노치·홈 바 피해서), 세로 고정, 도트 게임기 아이콘, 이름 '포켓보이'
