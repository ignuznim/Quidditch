# Game Brief: 퀴디치 포켓

After play: 게임보이 기기 재현을 좀더 디테일하게 해줘. 지금은 폰트나 버튼의 모양이 정확하지 않은 것 같아. 플레이어 인원수가 실제 퀴디치처럼 많으면 좋겠고, 공 종류도 실제 개수와 같길 원해. 방망이로 공을 쳐서 날리는 행위를 하는 플레이어도 두고, 나는 파수꾼 역할을 부여하면 좋겠어.

**Pitch:** 알록달록한 도트 화면에서 그리핀도르의 파수꾼이 되어, 7 대 7로 날아다니는 퀴디치 경기 속에서 골대 세 개를 몸으로 지키고, 막아낸 퀘이플을 추격꾼에게 던져 반격을 여는 캐주얼 공중 구기 *(inferred (strong))*

**Genre:** 아케이드 스포츠 + 비행 *(inferred (strong))*

**Controls:** 키보드: 방향키/WASD 이동, Z(A) 짧게 = 추격꾼에게 패스, 길게 눌렀다 떼기 = 누른 방향으로 멀리 던지기, X(B) 또는 퀘이플 없이 Z = 몸 날려 막기(돌진), Enter 일시정지, M 소리. 휴대폰·게임기 틀: 십자키, A·B, START(일시정지), SELECT(소리)

**Question:** 파수꾼이 되어 7 대 7 퀴디치의 골대를 지키는 게 2분 안팎 한 판으로 재미있는가? *(guessed)*

**Hooks:** 실제 퀴디치 그대로: 팀마다 파수꾼 1·추격꾼 3·몰이꾼 2·수색꾼 1, 공은 퀘이플 1·블러저 2·골든 스니치 1. 몰이꾼이 방망이로 블러저를 쳐서 상대에게 날리고, 나는 파수꾼으로 슛을 몸으로 막는다(내 선방은 확률이 아니라 위치와 타이밍). 수색꾼이 스니치를 잡으면 +150점에 경기 끝. *(you said, inferred (strong))*

**Intent:** payoff builds *(provisional)*: 골든 스니치는 60초에 나타나고, 10초 동안은 수색꾼이 찾기만 한다.

## Look and references
- Look: 알록달록한 도트 스타일. 파란 하늘 띠와 체크무늬 섞기, 흰 구름, 초록 언덕, 깃발 단 돌탑, 알록달록한 관중석. 우리 팀 '그리핀도르'는 주황 두건과 망토, 상대 '슬리데린'는 청록 옷에 뾰족한 검은 모자와 금빛 부리, 퀘이플는 빨간 공, 블러저는 주황 불꽃 테두리의 검은 쇠공, 골든 스니치는 흰 날개의 금빛 공. 외곽선은 1픽셀 진남색, 음영 없음. 글자는 도트가 아니라 화면 해상도로 또렷하게. 대표 디테일: 고리 위 등불과 하늘의 등불 줄이 골 때 깜빡이고 관중이 뛰어오른다. 모든 선수와 공은 도트로 그리고, 이모지나 그냥 동그라미는 쓰지 않는다.
- References: 없음
- View: 2D · Camera: 옆에서 보는 화면이 내 선수를 따라 좌우로 스크롤, 256x160 도트 화면을 또렷하게 키움 *(provisional)*

## First minute
경기장 가운데로 퀘이플이 떠오르고 양 팀 추격꾼이 달려든다. 나는 왼쪽 골대 셋 앞에 떠 있는 파수꾼. 방향키로 골대 앞을 오르내려 보고, 슬리데린 추격꾼이 다가와 슛을 쏘면 몸으로 막거나 X로 몸을 날려 '선방!'. 잡은 퀘이플을 Z 짧게 눌러 우리 추격꾼에게 패스하면 반격이 시작되고, 그 사이 몰이꾼들이 방망이로 블러저를 쳐 서로를 맞힌다. *(guessed)*

## Challenge
처음 30초는 슬리데린이 느슨하게 공격한다(빗나가는 슛이 많다). 1분쯤부터 더 빨리 날아와 정확하게 쏘고, 패스를 가로채고, 상대 몰이꾼이 내가 퀘이플을 들고 있을 때 블러저를 날린다. 지면 결과 화면에서 바로 다시 한다. 지고 있는 팀은 반짝이가 붙고 조금 빨라진다. *(provisional)*

## Core loop
- 슬리데린의 공격을 읽고 골대 앞을 오르내리며 자리를 잡는다
- 슛을 몸이나 몸 날리기로 막는다(선방); 놓치면 실점 10점
- 잡은 퀘이플을 비어 있는 추격꾼에게 패스하거나 멀리 던져 반격을 연다; 들고 있으면 상대 몰이꾼의 블러저가 날아온다
- 우리 추격꾼이 골을 넣으면 +10, 수색꾼 싸움이 끝나면(+150) 경기 끝
- Leads: 스포츠가 득점·경기장·시간을, 비행이 조작감과 화면 스크롤을 이끈다 *(inferred (strong))*

## Goal & fail state
- 수색꾼이 골든 스니치를 잡으면(+150) 경기 끝; 3분이 지나면 점수 높은 팀이 승리 *(provisional)*
- 끝났을 때 점수가 낮으면 패배, 결과 화면에서 선방·실점·패스 수를 보고 바로 다시 하기 *(provisional)*

## Features
- [x] 옆에서 보는 2D 비행: 8방향 이동과 약간의 관성, 몸 날리기(돌진)
- [x] 실제 퀴디치 인원: 팀마다 파수꾼 1·추격꾼 3·몰이꾼 2·수색꾼 1 (14명)
- [x] 나는 그리핀도르 파수꾼: 위치와 타이밍으로 막는 선방, 짧게 패스·길게 멀리 던지기
- [x] 추격꾼 AI: 패스, 압박, 빼앗기, 슛; 상대 파수꾼 AI의 선방
- [x] 실제 공 개수: 퀘이플 1, 블러저 2, 골든 스니치 1
- [x] 몰이꾼: 방망이로 블러저를 쳐서 상대(특히 퀘이플을 든 선수)에게 날림, 맞으면 휘청하며 공을 놓침
- [x] 골든 스니치: 60초에 등장, 10초 동안은 찾기만, 수색꾼끼리 경쟁, 잡으면 +150과 경기 끝
- [x] 점수와 시계, 지는 팀 보너스, 결과 화면과 다시 하기
- [ ] 알록달록한 도트 그림과 또렷한 글자, 골 등불과 관중 연출, 삑삑 효과음
- [x] 휴대폰 터치 조작: 십자키와 A·B·START·SELECT, 세로·가로 화면
- [x] 손안의 게임기 틀: 회색 본체, 줄무늬와 전원 불빛이 있는 화면 테두리, 검은 십자키, 기울어진 A·B, SELECT·START, 스피커 구멍 (실제 회사 로고와 상표 글씨는 빼고 우리 이름)
